# どうぶつしょうぎ 定跡・戦略ガイド

このファイルは、将来の「攻略サイト」コンテンツと CPU の強さ調整(`js/cpu-ai.js`)の両方が参照する
戦略知識のマスターデータです。出典は以下の4つ。

- [note.com/nerozou「どうぶつしょうぎ定跡研究」前編](https://note.com/nerozou/n/n00e0d94181d0)
- [note.com/nerozou「どうぶつしょうぎ定跡研究」後編(7大定跡)](https://note.com/nerozou/n/n6c3dbd93a665)
- [田中哲朗(東京大学)「どうぶつしょうぎの完全解析」](https://www.tanaka.ecc.u-tokyo.ac.jp/ktanaka/dobutsushogi/20090626.pptx.pdf)(コンピュータによる全局面探索の学術発表資料)
- [xawa99「どうぶつしょうぎ完全解析 B2ひよこ」](https://xawa99.blogspot.com/2013/04/DoubutsuShougi-Kaiseki-B2Hiyoko.html)(田中哲朗氏の完全解析データを元にした、初手ごとの精密な手順解説シリーズ)

座標表記は将棋式(列 A〜C、段 1〜4。1段目が後手陣、4段目が先手陣)。本プロジェクトの内部表現
(`row`/`col`、`row0`=後手最奥、`row3`=先手最奥)とは軸が違うので、CPUロジックに反映する際は
`col: A=0,B=1,C=2` / `row: 将棋の段 → row = 段-1` で変換すること。

## 0. 大前提(完全解析で判明している事実)

田中哲朗氏の研究により、どうぶつしょうぎは**コンピュータで完全解析済み**。

- 標準の初期配置は **後手(先攻ではない側)の必勝**。最短で **78手** で後手が勝つ。
- 先手からの最善の応手でも数手しか縮められない(「B2ヒヨコ」に対し「同ぞう」なら76手、
  「C3キリン」に対し「A2キリン」なら78手)。
- 勝ち局面は全体の約36%(56,474,473 / 155,299,864、末端局面除く)、負け局面は約26%、
  残りが引き分け筋を含む「まだ勝敗未確定」の局面。
- **勝ち局面の約30%には「詰み」がある**(王手の連続だけで受け無しに勝てる)。詰み手数は
  1手が最多(11,520,862局面)で、手数が伸びるほど急激に減る。→ **終盤は「王手ラッシュで詰むかどうか」を
  最優先でチェックする価値が高い**、というのが定量的な裏付け。
- 「ツークツワンク局面」(自分から動かなければ勝ちなのに、動かねばならないせいで負ける局面)が
  21,839個確認されている。**どうぶつしょうぎは"手を作れず手詰まりで悪化する"事故が起きやすいゲーム**、
  という裏付けになる。
- 敵陣への「ひよこ打ち」は将棋と違って反則ではないが、一般には悪手。禁止ルールにすると
  4,301局面で勝敗が変わる(ただし初期局面の後手78手勝ちという結論自体は変わらない)。

これらは「上級者向けの豆知識」であり、そのままでは初心者の指針にならない。以下、実戦で使える
形に落とし込んだのが第1〜3節。

## 1. 初級(ルールを覚える・かんたんCPU相当)

**対象**: ルールを覚えたばかり〜数局しか指していない人。CPU「かんたん」の想定相手。

### 覚えること
- 駒の動き(ライオン=8方向、ゾウ=斜め4方向、キリン=たてよこ4方向、ヒヨコ=前1マス、
  ニワトリ=斜め後ろ以外の6方向)。
- 勝ち方は2種類: **キャッチ**(相手ライオンを取る)と **トライ**(自分のライオンが相手の
  一番奥の列まで無事に到達する)。
- **ヒヨコが成る**のは相手陣(自分から見て一番奥の列)に入ったとき。成ったら「ニワトリ」で
  動きが広がる。
- 持ち駒は空いているマスに自由に打てる(将棋と違って「二歩」「打ち歩詰め」「一段目への
  歩打ち」のような反則が一切ない)。ただし敵陣への「ひよこ打ち」は反則ではないが
  基本的には悪手 — 前進していないヒヨコを敵陣に置いても、すぐ成れるだけで駒の働きが薄い。

### 初心者が最初に意識すべき3つ
1. **ライオンを絶対に無防備にしない。** 動かすときは「動かした後、次に相手の駒で取られないか」を
   必ず数える。
2. **自分から動けなくなる(ツークツワンク)状況を避ける。** 手がない、動くたびに悪くなる、という
   局面に自分から追い込まれないよう、駒を一箇所に固めすぎない。
3. **トライされそうになったら、その位置が「取れる位置」かどうかを先に確認する。** 相手のライオンが
   自陣の一番奥に来ても、次の手でこちらが取れるなら負けではない(取り逃すと負け)。

## 2. 中級(定跡の入口・ふつうCPU相当)

**対象**: ルールに慣れて、序盤の方針が欲しい人。CPU「ふつう」の想定相手。

### 2.1 先手の4つの初手

| 初手 | 特徴 | 合流・派生 |
|---|---|---|
| **B2ヒヨコ** | 相手のヒヨコを取りつつ王手をかける素直な手 | 「ゾウ冠」戦法へ。比較的穏やかな変化が多く**初心者におすすめの初手** |
| **C3キリン** | 大駒(キリン)を上げて上部を制圧しにいく手 | 「キリンの翼」戦法へ。ゾウ冠より複雑な変化が多い |
| **C3ライオン** | 有力とはされない手 | 最終的にC3キリンの変化に合流 |
| **A3ライオン** | 有力とはされない手 | 最終的にC3キリンの変化に合流 |

→ 実質的な選択肢は **B2ヒヨコ(ゾウ冠系)** か **C3キリン(キリンの翼系)** の2つと考えてよい。

### 2.2 二大戦法の考え方

**ゾウ冠(ぞうかん)**
- ライオンの頭に冠のようにゾウを配置して守りを固める出だし。
- 長手数になりやすく、激しい変化が少ないので**入門者向け**。
- B2ヒヨコから始まる本線で、先後とも大きな不満が出にくい。

**キリンの翼**
- キリンを両翼のように配置して盤面をコントロールする出だし。
- 先手の最善手は「C4キリン」(初期位置にキリンを戻す手)とされる。
- ゾウ冠より激しい変化に派生しやすく、読み間違えると即座に形勢が傾く。

### 2.3 中級者の駒組み方針
- **ライオンの周りをゾウ・キリンで固める**のが基本形(ゾウ冠、キリンの翼どちらも根っこは同じ)。
- ヒヨコは無理に前進させず、**取られない位置で相手の攻めを受け止める駒**として使う場面が多い。
  前進させるのは「成れる」「相手の駒を取れる」など明確な得がある時。
- 駒がぶつかったら**取り返せるかどうかを1手先まで数える**(捨て駒がまだ理解できない段階では、
  「損得ゼロ以上の交換」しかしないのが安全)。

## 3. 上級(7大定跡・千日手の見極め・詰みの読み)

**対象**: 序盤の方針を持って指せる人。CPU「つよい」〜それ以上の想定相手、
および将来の定跡データベース化の元ネタ。

### 3.1 7大定跡一覧

出典: note.com/nerozou 後編。手数は「完全解析上、後手が最短で必勝するまでの手数」。
千日手になりやすい定跡は、実戦的には先手側が得(後手が無理に踏み込まないと勝ちに届かない)。

| # | 定跡名 | 分岐元 | 必勝手数(後手) | 千日手傾向 | 実戦的な有利不利 |
|---|---|---|---|---|---|
| 1 | **ゾウ冠定跡** | (本線) | 75〜76手 | 低い | 先後とも不満なし |
| 2 | **控えのヒヨコ定跡** | ゾウ冠の5手目 | 72〜74手 | 高い | 先手有利(千日手に逃げやすい) |
| 3 | **ゾウ無双定跡** | ゾウ冠の9手目 | 56手 | 高い | 千日手になりやすい |
| 4 | **中キリン定跡** | キリンの翼系 | 68手 | 高い | 先手有力(千日手傾向) |
| 5 | **穴ライオン定跡** | キリンの翼系(珍しい変化) | 52手 | — | 研究例が少なく先手側に勝機あり |
| 6 | **ゾウキリン定跡** | (短手数の重要定跡) | 48手 | — | 短手数だが要注意の定跡 |
| 7 | **ゴキゲン中ライオン定跡** | — | — | — | **唯一の先手優勢の例外**。後手が強制的に引き込める |

### 3.2 初心者〜級位者向けショートカット「ネロ造メソッド」

7つ全部を覚えるのは非現実的なので、著者(nerozou氏)が提案する実戦的な絞り込み:

- **自分が先手のときは「中キリン定跡」だけ研究する。**
- **自分が後手のときは「ゴキゲン中ライオン定跡」だけ研究する。**
- 先後それぞれ1つの定跡に絞ることで、限られた勉強時間で勝率を素早く上げられる。
- ただし **2〜3級程度までの級位者向け** で、高段者相手には通用しにくいと明言されている
  (定跡を外れた瞬間に地力の差が出るため)。

### 3.3 終盤の考え方(完全解析の知見を実戦に落とす)

- 勝ち局面の約30%に詰みがある、というデータから、**駒がぶつかり合う終盤戦では「王手を連続でかけて
  詰むかどうか」を毎回チェックする**のが上級者の基本動作。詰みがあるのに緩めると、相手に
  ツークツワンク回避や千日手に逃げるチャンスを与えてしまう。
- **千日手を狙うのは基本的に劣勢側の作戦。** 上の表で「千日手傾向が高い」定跡は先手(あるいは
  劣勢の側)が同一局面を3回作って引き分けに逃げ込む筋を含む。自分が優勢なら、同じ局面を
  繰り返す手を避けて踏み込む。
- **トライの受けは「取れる位置かどうか」の1点に尽きる。** 相手のライオンが自陣最奥列に来ても、
  次の手で取れる位置なら負けではない。逆に自分がトライするときは、相手の駒の利きが
  届かないマスを選ぶ。

### 3.4 実戦定跡の具体例: B2ひよこ定跡の精密解析

xawa99氏のブログは、田中哲朗氏の完全解析データを元に、初手ごとの最善手順をより細かく
追った解説シリーズ。学術資料(第0節)の「B2ヒヨコ→同ぞうで76手」という結論と一致しており、
具体的な指し手の裏付けとして使える。

**初手ごとの後手必勝手数(相互に整合)**

| 初手 | 後手必勝手数 |
|---|---|
| B2ひよこ | 76手 |
| C3きりん | 78手 |
| C3ライオン / A3ライオン | 78手 |

→ **初手による差はごくわずか**(2手程度)。どの初手を指しても大勢に影響はなく、
第2節の「初心者はB2ヒヨコ(ゾウ冠系)が指しやすい」という方針と矛盾しない。

**B2ひよこ定跡・相腰掛ぞう基本形の序盤**

```
▲B2ひよこ  △同ゾウ  ▲B3ゾウ  △A2きりん  ▲A2同ゾウ
```

このあと後手は **20手目まで「勝ちにつながる手が各局面で1つしかない」** という極めて
狭い道を通る必要がある(それ以外の手を指すと先手勝ちの局面に転落する)。
→ 「定跡は知っていれば強いが、うろ覚えでは逆に事故る」ことの好例。実戦的には
**この変化に飛び込む先手側の方が、後手のミスを誘いやすく勝ちやすい**とも言える。

**中盤の要点**

- **△B2ひよこ打**が唯一の正着とされる強手(これ以外は後手が負ける)。
- その後 `▲同ゾウ 、△A3ゾウ打 、▲A4ライオン 、△C1ライオン 、▲C4きりん 、△B2ゾウ`
  と進み、**▲B2同ひよこ、△同ライオン以下で先手がツークツワンク(手詰まり)に陥る**。
  第0節で触れた「21,839個のツークツワンク局面」が実戦でどう発生するかの具体例になっている。
- 先手はやむを得ず `▲B4ゾウ` と指すが、`△同ひよこ成、▲同ライオン、△B3ゾウ打` で
  後手の勝ち手順が複数出現する(22手目以降、選択の幅が広がる)。
- 終盤、先手は `▲C1キリン打` という強襲を見せるが、ここで駒を取ると即負けになる罠。
  → **「取れるから取る」ではなく「取った後の局面を読む」ことの重要性を示す典型例。**

**実装上の意味**: この変化は「後手が正着を外すと即座に先手勝ちに転落する」狭い一本道が
20手続く。CPUの「つよい」相当にこの定跡を実装する場合、**後手番のときだけこの手順を
最優先で参照する価値が高い**(先手番でこの定跡に沿って指しても、正しく受けられれば
理論上後手に勝てないため)。

## 4. CPUの強さへのマッピング(実装指針)

現状の `js/cpu-ai.js` はミニマックス+アルファベータ探索のみで、定跡データは未使用。
このガイドを将来 CPU に組み込む際の対応方針:

| CPU難易度 | 現状の実装 | このガイドを反映する場合の方向性 |
|---|---|---|
| **かんたん** | 完全ランダム | そのままでよい(第1節の「初心者が最初に意識すべき3つ」レベルの知識すら使わない想定) |
| **ふつう** | 2手読みのミニマックス | 序盤数手だけ「第2節: B2ヒヨコ／C3キリンの2択」から選ばせる、程度の軽い定跡バイアスが妥当 |
| **つよい** | 4手読みのミニマックス | 序盤は「第3節の7大定跡」の手順をデータベース化して優先し、定跡を外れたら通常の探索に切り替える。終盤は「詰みチェックを最優先する」評価関数の重み付けを追加すると、完全解析の知見(勝ち局面の30%に詰みあり)と整合する |
| **(将来案)最強** | 未実装 | 完全解析データそのもの、または詰み探索を深くした専用ルーチンを使えば理論上無敵にできる(田中哲朗研究の後退解析データが公開されていれば理想だが、現状は非公開/非常に大きい) |

### 定跡データを構造化する場合のフォーマット案

将来、定跡を `js/joseki.json` のような機械可読データにする場合は、この表のレコードを
以下の形にすると実装しやすい:

```json
{
  "name": "ゾウ冠定跡",
  "moves": ["B2ヒヨコ", "同ぞう", "..."],
  "winner": "gote",
  "movesToWin": [75, 76],
  "drawTendency": "low",
  "recommendedFor": ["sente", "gote"],
  "notes": "先後とも不満のない本線"
}
```

`moves` は将棋式記法のままだと自動生成が難しいので、実装時は `{ from, to }` または
`{ drop, to }` の座標配列に変換すること(本ファイル冒頭の座標変換ルールを参照)。

  一次情報ではなく、記事内で述べられている結論をそのまま引用している。記事化する際は
  出典リンクを明記すること。

  (B2ひよこ=76手など)が学術資料の数値と一致しており、裏付けの取れた情報として扱ってよい。
